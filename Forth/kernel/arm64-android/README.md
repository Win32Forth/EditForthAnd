# arm64-android kernel sources

NDK / Clang GAS assembly for Android **arm64-v8a** (PIC shared library).

- Source of truth: `../arm64` (Windows ARM64 armasm).
- Generated by `GrokTools/arm64_to_android_gas.py` (all `*.S` except `identity.S`).
- Hand-maintained: `identity.S` (banner strings).
- Future sibling: `../x86_64-android` for emulator ABIs if needed.

Regenerate after editing the Windows arm64 sources:

```bash
python3 GrokTools/arm64_to_android_gas.py
```

Qt links these into `libforthnative.so` from `Edit/CMakeLists.txt` together with
`Forth/host/android` (`emit_buf.c`, `host_android.c`, `host_float.c`).
